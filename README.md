# Form Table Website
**Form Table Website** is a responsive and interactive web application built using **React, HTML5, and Tailwind CSS**. It allows users to input data through a form and display the submitted details dynamically in a table format. The app focuses on simplicity, real-time updates, and a smooth user experience.

# Features
- **Dynamic Form Handling** – Add and manage user data through a simple form
- **Table Display** – View submitted data instantly in a structured table format
- **Responsive Layout** – Works seamlessly on desktops, tablets, and mobile devices
- **Add & Clear Functions** – Easily add new entries or reset the form
- **Real-Time Updates** – Instantly updates the table when data is entered
- **Modern UI** – Clean and minimal interface for better usability

# Technologies Used
- **React** – for building dynamic and reusable components
- **Tailwind CSS** – for fast, responsive, and utility-based styling
- **HTML5** – for semantic structure and accessibility

# How It Works
Fill in the form fields with the required data
Click the Add button to submit your entry
The submitted data will appear instantly in the table below
You can continue adding multiple entries — all updates happen dynamically
